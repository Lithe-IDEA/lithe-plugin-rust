0.1.0 是 Rust Support 的第一个版本：rust-analyzer 代码智能、构建窗口里的 Cargo、用 CodeLLDB 调试，以及「新建项目」里的 Rust。它取代 `lithe-plugin-cargo`，Cargo 构建系统并入这里。这个版本需要支持下载型命令安装器的新版 Lithe 桌面端，因此作为预发布版本发布。

功能：
- 代码智能：补全、跳转定义、悬停、诊断和格式化由你自己的 rust-analyzer 提供。每次启动前插件按项目目录选出 rustup 工具链（`rustup run <工具链> rust-analyzer`），工具链缺少 rust-analyzer 时先运行 `rustup component add rust-analyzer rust-src`，可在设置里关闭。保存时运行 `cargo check`，可改成 `cargo clippy`，改完不需要重启语言服务器。
- 识别软件包：含 `Cargo.toml` 的最外层目录是构建根，`cargo metadata --no-deps` 的结果组成软件包和二进制、示例、库目标，读取时不联网。`Cargo.toml`、`Cargo.lock`、`.cargo/config(.toml)`、`rust-toolchain(.toml)` 变化后重新读取。
- 构建：Build、Check、Clippy 可作用于工作区、单个软件包或单个目标，Doc 和 Clean 作用于工作区或软件包；编译错误显示为问题。依赖列表按 `cargo tree` 的样子列出。
- 运行：每个二进制和示例在构建窗口里有运行按钮；打开 `src/main.rs`、`src/bin/*.rs`、`examples/*.rs` 时编辑器里也有运行入口。
- 构建选项：Release Profile、Features（按软件包列出）、All Features、No Default Features、Offline，会加到构建、检查、运行和调试的命令里。
- 调试：构建窗口里二进制和示例的「调试」先构建，再用 CodeLLDB 启动程序，支持断点、单步、调用栈和变量。CodeLLDB 不在插件包里：在「设置 → 插件 → 已安装 → Rust Support → 功能」点调试器卡片上的安装，Lithe 下载 CodeLLDB 1.12.3（Apple Silicon 的包约 45 MB），核对 SHA-256 后放进插件状态目录。
- 新建项目：「新建项目」里的 Rust 可以选 Cargo、二进制或库、软件包名和 Edition，由模板写出 `Cargo.toml`、`.gitignore` 和源文件，不需要联网。
- 工具链：「构建、执行、部署 › 工具链」列出电脑上的 cargo、rustup 和 rust-analyzer，项目可以固定用其中一个 Cargo。

已知限制：
- 不提供测试：构建窗口里没有测试树，也不能单独运行或调试一个测试。
- 调试只支持启动，不支持附加到运行中的进程；编辑器里的运行入口不能调试。
- 从经过符号链接的路径打开项目时（例如从 macOS 的 `/tmp` 打开），断点不会停下；从真实路径打开项目即可。
- Windows ARM64 上没有调试：CodeLLDB 1.12.3 没有发布这个平台的包。其他功能可用。
- 工作区成员在打开的文件夹之外时不列出。
- 新建项目的字段、工具定义和调试器的名称只有英文。
- 不要和 `lithe-plugin-cargo` 同时启用，两个插件都声明了 `cargo` 构建系统。

验证：
- 在 macOS 上用宿主的 workbench 集成测试装上插件包：Cargo 软件包和目标出现在构建窗口，Build 和运行成功，Features 会加到命令里，rust-analyzer 报出代码里的诊断；按需下载并校验 CodeLLDB 1.12.3，在断点处停下、读到局部变量，继续后程序正常结束；插件包的文件不变。
- 在 macOS 上用宿主的新建项目测试生成二进制和库软件包：二进制能 `cargo run`，库的 `cargo test` 通过，项目固定的 Cargo 来自工具定义找到的安装，带空格的软件包名被表单拒绝。
- 后端的单元测试在 macOS、Windows x64 和 Windows ARM64 上运行。
- 还没有在 Lithe 里手工验收，也没有在 Windows 版 Lithe 里运行过，状态见 `docs/feature-matrix.md`。

权限：启动插件后端、启动语言服务器、启动调试器、安装命令行工具（下载 CodeLLDB）、运行构建进程、生成项目、读取工作区信息。

兼容性：
- 按插件契约 v0 编写，只能装进新版 Lithe 桌面端（`desktop-v*` 预发布）。
- 下载 CodeLLDB 需要下载型命令安装器（1lck/Lithe-IDEA#2241，固定了 Lithe-core-rust#133 的 Core）；桌面端 0.8.11 及更早版本拒绝安装这个插件。
- rustup 安装的 cargo 和 rust-analyzer 是指向 rustup 的链接，macOS 上工具链页要显示它们的版本、项目要固定 rustup 的 Cargo，需要包含 Lithe-core-rust#135 的桌面端（1lck/Lithe-IDEA#2242）。
